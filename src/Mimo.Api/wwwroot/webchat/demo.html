Página demo del WebChat embebible

Esta página simula el sitio de un cliente que incrusta el widget. El botón de chat aparece abajo a la derecha. Snippet usado:

<script src="/webchat/widget.js" data-tenant="andinashop"></script>

Para probar contra otro tenant, cambia data-tenant. Para apuntar a otra API, agrega data-api="https://mi-api".
